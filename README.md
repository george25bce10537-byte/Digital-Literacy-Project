## Project Overview
This repository contains my Digital Literacy Project submitted for the CSE0001 course at VIT Bhopal University. The project is based on the role of a Student Digital Ambassador and focuses on developing awareness and practical skills related to digital tools, professional online presence, coding platforms, communication etiquette, and cyber safety.

- Covered digital literacy, safe internet practices, and email etiquette
